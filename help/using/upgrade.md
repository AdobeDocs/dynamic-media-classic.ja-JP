# [!DNL Dynamic Media]にアップグレードする理由

Adobeがニーズに合わせて[!DNL Dynamic Media]を作成しました。

[!DNL Adobe Experience Manager]の新しい[!DNL Dynamic Media]は、[!DNL Dynamic Media Classic] （旧Scene7）に期待される機能に基づいて構築されます。 これにより、より優れた魅力的なエクスペリエンスを構築するための、新しいツールや改善されたツールが手に入ります。

[!DNL Dynamic Media]は、リアルタイムのビジュアル ビルダーを使用して、コンテンツ構築エクスペリエンスをアップグレードします。 Adobeのスケーラブルな配信ネットワークと、直感的な[!DNL Adobe Experience Manager] ユーザーインターフェイスを組み合わせて利用することで、[!DNL Dynamic Media]は、魅力的で高度なエクスペリエンスをオーサリング、繰り返し、配信する機能を提供します。

| [!DNL Dynamic Media]で得られるもの | 説明 |
| --- | --- |
| プライマリファイル形式 | フルサイズのアセットをアップロードすると、[!DNL Dynamic Media]が必要に応じてサイズを自動的に作成します。 |
| 手軽なオーサリング | テクノロジーの知識がなくても、リッチなエクスペリエンスをすばやく構築、カスタマイズ、公開できます。 |

## [!DNL Dynamic Media]の主な利点と機能

[!DNL Dynamic Media]は[!DNL Dynamic Media Classic]の後継です。 リッチメディアのオーサリング、公開、配信ツールセットを提供します。 また、革新的でユーザー中心のインターフェイスを備えた高品質な配信機能も備えており、最新のワークフローを促進します。

* シームレスで統合されたエクスペリエンスと[!DNL Adobe Experience Manager]との統合：1つのストア、1つのソースからリッチコンテンツを設定して動的に配信します
* リッチメディアコンテンツのオーサリングと配信を簡単にする、マーケティングを重視した新しいユーザーエクスペリエンス
* 全体的なルックアンドフィールを実現するビジュアル編集や、画像ビューアおよびビデオプレーヤー向けのビヘイビアーエディターを利用できます。
* 画像のホットスポットやショッパブルビデオなど、ショッパブル/インタラクティブメディア体験の作成と展開を高速化

## Adobeを選ぶ理由？

* デジタルアセット分野のベンダーとして評価されているForresterのWAVE レポート。
* 2016年のオンライン動画プラットフォームのレポートで高いパフォーマンスを発揮。
* トップのリッチメディアプロバイダーからインターネット小売業1000、9年連続。
* サポート期間24時間365日、SLA99.95%、Adobe Professional Services
* 実績のあるインフラストラクチャにより、世界中の800社以上の顧客、月間3.5 ペタバイトのトラフィック、管理に5億以上のアセットを提供。トラフィックが前年比で60%増加
