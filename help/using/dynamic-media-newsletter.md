# ![Dynamic Media ニュースレターのロゴ &#x200B;](/help/using/assets/dynamic-media-newsletter-logo.png)

>[!NOTE]
>
>現在、月刊ニュースレターは廃刊になっています。 ただし、以下のニュースレターのアーカイブにはアクセスできます。

Adobe Experience LeagueのDynamic Media ニュースレターでは、Dynamic MediaとAdobe Dynamic Media Classicについて学ぶことで、製品を効果的に使い始めることができます。

このアーカイブされたニュースレターでは、ハウツー動画やソリューションの概要など、貴重な知識構築リソースを見つけることができます。 また、画像プリセット、ビューアプリセット、ビデオプロファイルなどの主な機能の紹介もあります。
